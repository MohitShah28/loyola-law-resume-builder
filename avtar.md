## How to use this file

Paste this whole file into a new chat and ask one of:

- "Find current job postings that match this profile. Rank them by fit and say what is missing for each."
- "Here is a job posting: [paste]. Score it against this profile and tell me honestly whether I qualify."
- "What kinds of roles should I be applying to, and what would make me competitive for the ones I am not yet?"

**Instructions for the assistant reading this file:**

1. Match on what is actually here. Do not assume coursework, credentials, or practice areas that are not listed.
2. Respect the hard filters in "Eligibility" below — graduation date, bar status, work authorization, and location.
3. For each posting, state: why it fits, which requirements are unmet, and whether any unmet requirement is disqualifying (for example a required LL.M. or a degree in a field this student does not hold).
4. Never suggest claiming skills or experience that are not in this file. If a gap can be closed honestly — a course, a clinic, a certification, a bar registration — say exactly which one.
5. Prefer postings open to current law students or entry-level attorneys, in the locations listed, and say when a posting's deadline or start date conflicts with the graduation date.
